Herramientas Algorítmicas para Docentes

Automatización de procesos académicos mediante JavaScript

1. Secuencial: Carga Horaria

Estructura Lineal

Calcula el total de horas de un curso sumando las horas de clase presencial y el trabajo autónomo del estudiante.

2. Condicional: Nivel de Desempeño

Decisiones (if/else)

Clasifica el rendimiento de un estudiante según el decreto de evaluación (Bajo, Básico, Alto, Superior) basado en un puntaje de 0 a 100.

3. Iterativo: Generador de Rúbricas

Ciclos (while)

Crea automáticamente las filas para una rúbrica de evaluación dependiendo de cuántos criterios necesites calificar.
